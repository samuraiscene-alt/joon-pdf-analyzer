# JOON PDF ANALYZER

독립 부동산 경매 문서 판독 테스트 PWA.

## 목적
PDF, 스캔 PDF, 캡처 및 사진에서 문서 내용을 추출하고 임차인·권리관계·위험사항을 근거와 함께 정리합니다. 기존 부동산 경매앱은 수정하지 않습니다.

## 검증 원칙
- 최초 테스트는 처음 보는 문서를 앱에 직접 업로드하여 진행합니다.
- 앱이 분석 결과(JSON)를 먼저 내보내고, 그 이후에 사람과 원본을 대조합니다.
- 표의 행/열 복원과 OCR은 완전하지 않습니다. 판독 결과를 법률적 확정 판단으로 취급하지 않습니다.
- 법원 PDF 원본, 개인정보 및 API 키를 공개 저장소에 올리지 않습니다.
- 원본 파일과 분석 결과는 기본적으로 기기 내에서 처리하고 별도로 백업합니다.
